# AGROBULL Online — 3D multiplayer

Это отдельный проект игры AGROBULL. Он включает браузерный 3D-клиент на Three.js и сервер комнат на Node.js + Socket.IO.

## Что уже реализовано

- Горизонтальная игровая сцена, адаптация под компьютер и альбомный экран телефона.
- Процедурная 3D-сцена бара: деревянный пол и стены, круглый стол, металлическая отделка, кресла, лампы, туман и частицы пыли.
- Процедурные объёмные персонажи с разными лицами и силуэтами: Химик (лысина, очки, бородка), Адвокат (уложенные волосы и костюм), Напарник и Босс.
- Детализированный механический медный бык: металлический корпус, рога, ноги с сочленениями, копыта, шестерни, гидравлические элементы, заклёпки и седло.
- Анимация быка и вылета игрока с полётом, вращением и приземлением.
- Лобби: создание комнаты, 4-значный код, вход по коду, готовность игроков, запуск хостом.
- Онлайн-матч на 2–4 игроков через Socket.IO. Сервер проверяет ходы и блеф; каждому клиенту отправляется только его собственная рука карт.
- Игровые монеты и магазин костюмов. За победу начисляется 80 монет, за участие — 15.
- Оптимизация: ограничение pixel ratio, сглаживание, тени, адаптивный resize и оптимизированная геометрия процедурных моделей.

## Запуск на компьютере

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

Открой в браузере `http://localhost:3000`. Чтобы сыграть онлайн, второй и остальные игроки должны открыть тот же адрес сервера с другого устройства в той же сети или по публичному адресу.

## Публикация в интернете через Render

1. Создай новый GitHub-репозиторий и загрузи в него **содержимое этой папки** (`package.json`, `server.js`, `public/`, `render.yaml`, `README.md`).
2. В Render выбери **New → Web Service** и подключи этот репозиторий.
3. Runtime: `Node`. Build Command: `npm install`. Start Command: `npm start`.
4. После публикации открой выданный Render URL. Разошли эту ссылку друзьям — все должны заходить на один и тот же адрес.

`render.yaml` содержит те же команды и может использоваться для Blueprint deploy.

## Важные ограничения текущей версии

- Игровые комнаты существуют в оперативной памяти сервера. После перезапуска или сна бесплатного хостинга незаконченные комнаты исчезнут.
- Монеты, выбранный герой и купленные скины пока хранятся в `localStorage` браузера. Это игровой прототип, а не защищённая серверная экономика: баланс можно сбросить или изменить в браузере. Для постоянных аккаунтов нужен вход по учётной записи и база данных.
- Внешние Three.js и Google Fonts загружаются через CDN, поэтому для полной графики нужен интернет.
- 3D-модели создаются процедурно из геометрии и материалов. Это не фотограмметрия и не AAA-сканированные модели; внешний вид будет зависеть от мощности устройства и качества WebGL.
- Персонажи сделаны как игровые образы, вдохновлённые типажами сериала, а не как официальные модели или текстуры из сериала.
